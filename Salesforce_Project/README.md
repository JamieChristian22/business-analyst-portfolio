# Salesforce Sales Pipeline Analytics

## Overview
End-to-end Business Analyst project analyzing sales pipeline performance, forecasting revenue, and identifying growth opportunities.

## KPIs
- Total Pipeline: $164000
- Weighted Pipeline: $83550.0
- Average Deal Size: $16400.0
