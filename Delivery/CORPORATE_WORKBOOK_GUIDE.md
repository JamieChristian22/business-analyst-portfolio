# Corporate delivery workbook

Open `Portfolio_Delivery_Tracker.xlsx`. The Dashboard summarizes six projects and includes an editable project filter, report date and native chart. Eight tabs cover requirements, UAT execution, gap analysis, RAID, change control, defects and operating guidance.

All 48 requirements, 144 planned UAT cases and 48 detailed gaps are retained. Amber cells identify execution inputs. Gray cells calculate linked test coverage, evidence readiness, approval gates, closure gates and overdue flags. Due dates are blank until agreed. Business approval is not inferred from completed code or analysis.

Use the ReadMe rules before editing. Workbook edits do not automatically update CSV registers or the local application. Excel supports management review; the local application provides role enforcement and audit history. Formula ranges cover this supplied portfolio; extend them when adding records.

The previous three-tab tracker is preserved in `../Legacy/Portfolio_Delivery_Tracker_v2.xlsx`. Original project Excel files remain in the project Legacy folders.

## Diagram handoff

Each project's Diagrams folder includes a professional swimlane process as editable `.drawio`, scalable `.svg` and presentation-ready `.png`. Open the `.drawio` in diagrams.net to move shapes and connectors. The diagrams use Visio-style conventions; they are not native VSDX files. Local controls are implemented, while business-role handoffs and signoff remain pending until executed.
