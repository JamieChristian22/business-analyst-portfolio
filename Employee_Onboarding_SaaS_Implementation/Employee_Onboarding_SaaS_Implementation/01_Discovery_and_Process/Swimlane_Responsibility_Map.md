# BPMN-style lane ownership (proposed)
| Stage | HR | Manager | SaaS platform | IAM / integration | IT |
|---|---|---|---|---|---|
| Intake | Responsible | Informed | Validate | — | — |
| Approval | Informed | Accountable | Route and timestamp | — | — |
| Integration | Informed | Informed | Publish event | Map/transform | Monitor |
| Provisioning | Informed | Informed | Track state | Execute standard roles | Handle exceptions |
| Closure | Verify | Verify | Notify and log | Report result | Confirm support handoff |

BPMN conventions: start/end events; tasks; exclusive gateways for validation, approval and provisioning; exception paths with explicit ownership. Mermaid files are conceptual flowcharts rather than certified BPMN 2.0 XML.
