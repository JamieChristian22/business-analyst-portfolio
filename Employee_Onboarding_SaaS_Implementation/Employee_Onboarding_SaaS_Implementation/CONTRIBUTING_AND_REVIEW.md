# Review and customization guide
1. Compare each artifact with your actual Lucidchart/Postman/Jira work.
2. Export sanitized source evidence and place it under `00_Evidence/Actual_Exports/`.
3. Replace hypothetical assumptions only after stakeholder confirmation.
4. Keep proposed architecture and unexecuted tests explicitly labeled.
5. Check Mermaid syntax in your preferred renderer; flowcharts are not BPMN XML.
6. Update the evidence register and traceability matrix as new tests are actually executed.
7. Link this project from the main repository README, and optionally cross-link from your Systems Analyst portfolio.
8. If you run the Postman collection, record execution date, environment, actual responses, and any differences from the observed October 15 lab.
