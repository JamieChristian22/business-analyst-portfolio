# 📊 Amazon Marketplace Analytics Project – Jira (Agile Execution)

## 📌 Overview

This section of the project demonstrates how Agile methodologies were used to manage and deliver an end-to-end analytics solution for Amazon Marketplace performance tracking. The project was executed using Jira to simulate a real-world Scrum environment.

The focus was on backlog management, sprint planning, user story creation, and tracking analytics feature delivery.

---

## 🎯 Project Objective

To design and deliver a data-driven analytics dashboard that provides insights into:

* Sales performance
* Product trends
* Customer behavior
* Revenue optimization opportunities

---

## ⚙️ Agile Methodology (Scrum)

* Framework: Scrum
* Sprint Duration: 2 weeks
* Tools Used: Jira, Excel, SQL, Power BI

---

## 🧩 Key Responsibilities (Product Owner / Business Analyst Perspective)

* Defined product vision and analytics goals
* Created and prioritized product backlog
* Translated business requirements into user stories
* Wrote acceptance criteria for each feature
* Collaborated with stakeholders and development team
* Ensured backlog readiness for sprint planning

---

## 📝 Sample User Stories

### 📌 User Story 1: Sales Dashboard

**As a** business stakeholder
**I want** to view total sales performance
**So that** I can track revenue trends

**Acceptance Criteria:**

* Dashboard displays total revenue by date
* Filters available for product category and region
* Data updates dynamically

---

### 📌 User Story 2: Product Performance Analysis

**As a** product manager
**I want** to analyze top-performing products
**So that** I can optimize inventory and marketing

**Acceptance Criteria:**

* Top 10 products displayed by revenue
* Includes units sold and profit margin
* Sort and filter functionality enabled
